# Faculty Evaluation Rubric

Criteria, Documentation
- Developing: Missing diagrams or steps
- Proficient: Clear but shallow
- Advanced: Professional, includes threat models

Criteria, Prototyping
- Developing: Unstable environment
- Proficient: Working with minor issues
- Advanced: Optimized, efficient setup

Criteria, Functioning Model
- Developing: Defense not demonstrated
- Proficient: Stops basic attacks
- Advanced: Handles complex attacks and recovery

## Evidence checklist per worklet
- Before and after log or screenshot showing the attack failing
- Relevant log excerpt, such as IDS alert, WAF block, or auth failure
- Config file committed to the config or scripts folder
- Short lessons learned or limitations note in the worklet README
