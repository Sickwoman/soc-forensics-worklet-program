# Alert Severity Levels

Informational, level 0 to 3, example successful login or routine service restart
Low, level 4 to 7, example single failed login or config change
Medium, level 8 to 11, example multiple failed logins forming a brute force pattern, or a port scan
High, level 12 to 14, example privilege escalation or IDS signature match
Critical, level 15 and above, example confirmed intrusion or multiple correlated high severity events
