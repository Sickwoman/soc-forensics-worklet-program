Paste the following into VyOS configure mode

set interfaces ethernet eth0 vif 10 address 10.10.10.1/24
set interfaces ethernet eth0 vif 20 address 10.10.20.1/24
set interfaces ethernet eth0 vif 30 address 10.10.30.1/24

set firewall name IOT-TO-ADMIN default-action drop
set firewall name GUEST-TO-INTERNAL default-action drop

set interfaces ethernet eth0 vif 20 firewall in name IOT-TO-ADMIN
set interfaces ethernet eth0 vif 30 firewall in name GUEST-TO-INTERNAL

commit
save
